Install

  1. Tap Download APK above. Chrome will warn that this file type can harm your device — that warning shows for every APK outside the Play Store. Choose Download anyway.
  2. Open the downloaded file. Android will ask permission to install from this source — tap Settings, enable Allow from this source, then go back.
  3. Tap Install, then Open.

Updating from an older build? Just install over it — your settings are kept. The app also checks for new builds on its own and offers to update in place.

Server address

The app talks to a home server through a Cloudflare tunnel. This address is already built into the download above, so it should work straight away. If the tunnel has been restarted since this page was published, the address changes — paste the current one into the app under the gear icon → Server address.
